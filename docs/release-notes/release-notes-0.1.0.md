# 0.1.0

微博静净（QuietWeibo）首个公开版本，面向微博 Android 16.10.3。

## 功能

- 开屏、热启动开屏广告
- 首页/发现/关注/正文信息流广告
- 评论区广告、正文页底部通栏广告
- 发现页热搜下方通栏广告
- 首页顶导、下拉悬停、大视窗/浮层/弹窗、搜索/榜单、退屏/切页、广告重排
- 视频/直播悬浮广告
- 摇一摇/扭一扭广告跳转
- 广告预加载断源
- AD-14 跨版本动态兜底：扫描 DEX 类名补挂载点

## 安装

1. 安装 APK；
2. 在 LSPosed 中启用「微博静净」，作用域勾选 **微博（`com.sina.weibo`）**；
3. 强制停止微博后重新打开。

要求 Android 10+、支持 libxposed API 102 的 LSPosed / Vector。

## 验证范围

- 真机：OPPO PKH110 / Android 16 / LSPosed API 102
- 已验证：冷启动、首页信息流、正文页底部、评论区、发现页热搜下方通栏
- 静态锚点：60/60 通过；79 个 JVM 单测通过

## 说明

- 不伪造会员状态，不拦截网络，不修改账号数据。
- 仅 Hook 微博自己的业务类，不碰广告 SDK 内部。
- H5/小程序内部网页广告不在范围内。
- 与其它 Hook 微博的模块可能冲突，建议只保留一个。

对应源码：[fengwenhua/quietweibo](https://github.com/fengwenhua/quietweibo)。
