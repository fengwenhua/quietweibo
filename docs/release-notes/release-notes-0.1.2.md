# 0.1.2

适配微博 **16.11.0**，并改进兼容版本的展示方式。

## 兼容性

- 最新已测试兼容：微博 **16.11.0（versionCode 8250）**
- 继续兼容：微博 16.10.3（8234）
- 16.11.0 的 20 个应用 DEX 复验 **60/60 锚点通过**
- 真机日志确认 14 个功能全部挂载，AD-14 动态识别 23 个广告服务、1 个传感器

## 新增与改进

- 设置页顶部状态卡显示当前注入的微博版本是否在已测试清单内。
- 未测试版本显示红色高亮横幅，并说明仍按 16.10+ / 17+ 尽力兼容运行。
- 关于页「兼容版本」改为可滚动的嵌套页面，按从新到旧列出全部已测试版本；
  版本增多时自然滚动，不再受对话框高度限制。
- 支持系统返回键或页面内「返回关于页」回到关于主页。

## 安装

1. 安装 APK；
2. 在 LSPosed 中启用「微博静净」，作用域勾选 **微博（`com.sina.weibo`）**；
3. 强制停止微博后重新打开。

要求 Android 10+、支持 libxposed API 102 的 LSPosed / Vector。

## 验证

- 82 个 JVM 单测通过
- 16.11.0 真机冷启动、信息流、评论区、发现页等核心场景正常
- 静态锚点 60/60，无 critical/skip 类级失败

对应源码：[fengwenhua/quietweibo](https://github.com/fengwenhua/quietweibo)。
